Deborah D Amos Profile

A semantic HTML5 personal profile and mini-portfolio webpage created for the Web Technologies (CIS2103) Practical Assignment 1.

Project Description

This project is a one-page personal profile and mini-portfolio website for Deborah D Amos, a second-year Software Engineering student. The website introduces me, presents some of my skills, and provides a Contact Me form.

Website Features

The website includes:

A semantic HTML5 structure
Header with my name and tagline
Navigation links to different sections of the page
About Me section
Skills section
Contact Me section
Contact form with HTML5 validation
Meaningful alternative text for the profile image
Properly labelled form inputs
Responsive styling for smaller screens
Footer section
Semantic HTML5 Elements

The following semantic HTML5 elements are used:

<header> - Contains my profile image, name and tagline.
<nav> - Contains links to different sections of the webpage.
<main> - Contains the main content of the webpage.
<section> - Organises the About, Skills and Contact sections.
<article> - Contains individual pieces of information within the page.
<footer> - Contains the copyright information.
Contact Form

The Contact Me form contains different input types, including:

Text input for the user's name
Email input for the user's email address
Telephone input for the user's phone number
Text input for the subject
Textarea for the message
Submit button

HTML5 validation attributes such as required, type="email", pattern, and minlength are used to help validate the form without JavaScript.

Responsive Notes
Breakpoints Tested
-Mobile: 375px
-Tablet: 768px
-Desktop: 1280px
Layout Decision
-Flexbox: Used in the navigation bar to align links and allow them to wrap on smaller screens. Also used in the contact form to arrange fields vertically.
-CSS Grid: Used in the Skills section. The layout changes from one column on mobile to two columns on tablets and three columns on desktop.
-Media Queries: Custom min-width media queries adjust the Skills grid and spacing for larger screens.
Tailwind CSS
-Header: Tailwind utilities control responsive padding.
-Navigation: Tailwind utilities control responsive horizontal padding.
-Footer: Tailwind utilities control text size at different breakpoints.
